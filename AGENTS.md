# Codex / agents project instructions

При разработке этого репозитория **обязательно** прочитайте `CODEX_ПРОМПТ_Мир_Матвея_v10.md` и следуйте ему.

Приоритет: приложение помогает ребёнку Матвею, испытывающему трудности с речью, слушать, повторять короткие звуки и слова, жестами и голосом просить предметы и действовать в реальном мире с взрослым. Не заявлять о диагностике или терапии.

Не менять канонического персонажа: `assets/matvey-canonical-bear.png`. Всегда голубые глаза, каштановая чёлка, синяя толстовка, фиолетовый бант. Публикуемая PWA-иконка — этот же персонаж.

Сохраняйте PWA offline, все текущие игры, локальные пометки родителя в `localStorage`, клипы в IndexedDB; никакой БД/облака без явного разрешения. Без ответа не переходить дальше, минимум 3 секунды перед кнопкой следующего задания, поддержка долгого нажатия, адаптивность 320-1280px.

## Структура после v11

Сначала прочитайте `docs/V11.md`: в нём актуальная карта файлов, хранение и проверки.
Для изменения слов/заданий открывайте соответствующий `js/*-data.js`, для оформления v11 — `css/forest.css`, для арта — `assets/` и `js/artwork.js`. Не возвращайте изображения base64 в HTML. Не заменяйте модульную v11 старым монолитом из документа v10. При добавлении ресурсов обновляйте список через `python3 tools/update-cache.py` и повышайте CACHE в `sw.js`.

## 3D-раздел v12

Для «Лесного кафе» читайте `docs/V12.md`. Модели/сцена: `js/picnic-scene.js`; тексты: `js/picnic-data.js`; состояния: `js/picnic-game.js`; оформление: `css/picnic.css`. Локальную Three.js не редактировать вручную: `npm run vendor:three`. Офлайн-кэш должен включать вложенную папку `js/vendor/`. При выходе обязательно освобождать GPU и обработчики.

## Игры и обновление v13

Актуальная карта новых 3D-игр — `docs/V13.md`, тексты — `js/world-games-data.js`. Сцены используют общий рендерер кафе: при его изменении проверять все три мира. Для новой версии повышать не только CACHE, но и `v=` в HTML-ресурсах/ES-импортах, чтобы прежний Service Worker не выдал старый JavaScript. Не очищать хранилище пользователя для обновления.

## Графика v14

Графический набор: `js/storybook-art.js`; оформление и обложки: `css/vivid.css`; детали — `docs/V14.md`. Новые PNG хранятся локально в `assets/`. Не заменять объёмную механику скриншотами. При изменении материалов проверять освобождение всех texture maps и environment render target, а декоративной геометрии задавать ID родительской зоны касания.
