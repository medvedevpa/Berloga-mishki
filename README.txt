Мир Матвея v16 — локальная библиотека голоса родителя

Запуск: python3 -m http.server 8765
Открыть http://localhost:8765. Сборка и npm для самого приложения не нужны.
Размещать на GitHub Pages весь комплект: index.html, css/, js/, assets/,
manifest.webmanifest, sw.js и три корневые иконки.

Запись голоса и автоматическая подстановка: docs/V16.md.
Новые модели и публикация: docs/V15.md.
Графика v14: docs/V14.md.
Игры и обновление v13: docs/V13.md.
Лесное кафе: docs/V12.md.
Карта остальных файлов: docs/V11.md.
Настройки/прогресс/семейные награды: прежний localStorage speechplay.v3.
Записанный голос: прежняя IndexedDB speechplay-voice, схема не менялась.
Чтобы сохранить существующие данные, используйте прежний адрес и браузер.

После публикации дождитесь загрузки нового офлайн-комплекта и перезапустите PWA.
Удалять данные сайта или переустанавливать приложение для обновления не требуется.

На главной → «Лесное кафе · 3D»: беру, мою, мешаю, угощаю.
Для объёмной сцены нужен WebGL2; движок включён локально и доступен офлайн.

На главной перед остальными разделами — блок «Игры в 3D»:
«Лесное кафе», «Посылки для друзей», «Сад Матвея».
Если видна старая версия, откройте сайт с release-v16.html#cafe.
Есть кнопка «Обновить приложение», без удаления данных.

Разработка: исходники остаются в js/ и css/. После изменения: npm ci (однократно), npm run build.
Готовые js/release/v16/* и css/stylesheet-v16-* не редактировать вручную.
Исходник 3D-моделей: tools/build-models.py; пересборка через Blender: npm run models:build.
Для запуска готового комплекта npm и Blender не нужны.

Голос: удерживайте шестерёнку 1 секунду → «Голос» → «Ваш голос в игре».
Запишите 24 частые реплики; совпавшие фразы игра воспроизводит автоматически.
Для остальных реплик используется голос устройства. Генерации новых фраз вашим голосом нет.
Аудио остаются локально; доступны копия в файл и загрузка на другом устройстве.
