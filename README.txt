Мир Матвея v10 — полный комплект для GitHub Pages/PWA

Весь комплект загрузить в корень репозитория:
index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, apple-touch-icon.png.

Что нового:
- 12 игр в «Лесной школе»: + «Звуковое эхо» и «Волшебные слова».
- Иконка с исходным мишкой Матвеем (голубые глаза, каштановые волосы, синяя кофта, фиолетовый бант).
- ⚙️ → «Проверка карточек»: отмечать, скрывать, писать замечания, исправлять текст озвучки,
  экспортировать/импортировать JSON. Без базы данных. Настройки остаются в localStorage браузера.
- Запись голоса: нативное подавление шума, фильтрация гула и мягкий компрессор громкости;
  зависит от устройства и браузера; полноценную студийную очистку не заменяет.

На iPhone после обновления сайта/иконок удалите старую иконку с домашнего экрана,
откройте актуальный сайт в Safari и заново выберите «На экран Домой».
Для детского режима рекомендован Гид-доступ iOS.
