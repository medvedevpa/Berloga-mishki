Мир Матвея v11 — HTML, CSS, JavaScript и изображения отдельно

Запуск: python3 -m http.server 8765
Открыть http://localhost:8765. Сборка и npm для самого приложения не нужны.
Размещать на GitHub Pages весь комплект: index.html, css/, js/, assets/,
manifest.webmanifest, sw.js и три корневые иконки.

Карта файлов и результаты проверок: docs/V11.md.
Настройки/прогресс/семейные награды: прежний localStorage speechplay.v3.
Записанный голос: прежняя IndexedDB speechplay-voice, схема не менялась.
Чтобы сохранить существующие данные, используйте прежний адрес и браузер.

После публикации дождитесь загрузки нового офлайн-комплекта и перезапустите PWA.
Удалять данные сайта или переустанавливать приложение для обновления не требуется.
