# Мир Матвея v16 — голос родителя без облака

Взрослый записывает реплики один раз, а общий проигрыватель использует их во всех разделах: базовых занятиях, карточках, приключениях, мини-играх и трёх 3D-мирах. Несколько контрольных образцов **не создают новый синтетический голос**. Реализована локальная библиотека записанных фраз; незаписанный текст читает выбранный голос устройства. Аудио не передаются на сервер, сервисы клонирования и внешние API не подключены. Для TTS без интернета нужен локальный русский голос устройства; голоса браузера с пометкой «онлайн» зависят от сети.

## Как пользоваться

1. На главной удерживайте шестерёнку около секунды.
2. В разделе «Голос» откройте «Ваш голос в игре».
3. Начните с «Быстрый старт · 24 реплики». Нажмите «Записать», произнесите показанную фразу, затем «Стоп». Максимум — 30 секунд; автоматического перехода к следующей фразе нет.
4. Прослушайте результат. Для последней записи на этом экране можно сравнить «Послушать» с «До обработки». Исходный дубль для сравнения держится только в памяти до выхода из студии; в библиотеке остаётся выбранный обработанный результат.
5. «К следующей без записи» пропускает уже записанные фразы. В наборах есть слова и звуки, карточки, реплики всех 3D-игр и других разделов. Для своего текста используйте «Добавить свою фразу».
6. В списке «Игра прозвучала без записи» появляются встречавшиеся игровые реплики без соответствующего аудио (до 200 последних уникальных). Это помогает постепенно расширять библиотеку, включая изменённые родителем тексты карточек.
7. «Сохранить копию голоса» скачивает JSON с аудио. «Загрузить копию» добавляет недостающие записи на другом устройстве, не заменяя уже существующие. Копия проверяется целиком перед записью; ограничение — 40 МиБ аудио. Храните её как личный файл: она содержит ваш голос.

Записывайте в тихой комнате, без фоновой музыки, примерно в 15–20 см от микрофона. Если на устройстве нет русского TTS, записанные реплики всё равно доступны. Прослушивание в студии работает и при выключенной игровой озвучке.

## Подстановка

Сначала ищется запись всей реплики. Если её нет, текст разбивается по границам предложений/коротких команд; используются самые длинные совпавшие последовательности целых предложений. Например:

`ДАЙ. Зайчик просит яблоко. Выбери его на подносе.`

Если записано только «ДАЙ», первая команда звучит голосом родителя, оставшиеся предложения — голосом устройства. Для полностью собственной озвучки этого задания нужно записать и остальные предложения из набора 3D-игр. Слова не вырезаются из образцов и не склеиваются по слогам. «ДАЙ» не совпадает с «Отдай яблоко» или с серединой другого слова.

Сравнение не зависит от регистра, знаков препинания, дефисов и «е/ё». Прежние ключи IndexedDB читаются через нормализованные псевдонимы; массовой перезаписи базы нет. Длинная сохранённая реплика имеет приоритет над отдельными предложениями. Соседние незаписанные предложения читаются одним TTS-вызовом для связной интонации.

При смене экрана/повторе предыдущая речь отменяется, ожидающий игровой вызов завершается, старые обработчики и таймеры очищаются. При ошибке воспроизведения записи используется TTS; предпрослушивание конкретной записи не подменяется системным голосом.

## Запись и обработка

Микрофон включается только по нажатию взрослого. На время записи блокируются выбор другой фразы, удаление и импорт. Кнопка «Назад» отменяет текущий дубль и освобождает микрофон, в том числе если разрешение пришло с задержкой. При сворачивании активная запись останавливается и сохраняется; незавершённый запрос доступа отменяется.

Включённое улучшение просит браузер подавлять шум и автоматически регулировать входной уровень. После записи локально анализируется громкость, убираются паузы **только по краям**, ограниченно выравнивается уровень и создаётся моно WAV 24 кГц / 16 бит. Внутренние паузы, тембр и темп не заменяются. Есть настройка усиления; выходной пик ограничивается. Почти бесшумный дубль не заменяет прежнюю запись. Если декодирование/обработка кодека недоступны, сохраняется исходное аудио с соответствующим сообщением.

Это базовая обработка, не клонирование и не студийное шумоподавление. Фоновую музыку, эхо комнаты и плохой микрофон она гарантированно не исправляет. На реальном iPhone/iPad запись и ограничения автозапуска отдельно не проверялись; браузер может ограничивать воспроизведение без жеста пользователя.

## Файлы и хранение

| Файл | Назначение |
| --- | --- |
| `js/local-voice.js` | Нормализация, IndexedDB, подбор фраз, отмена воспроизведения, TTS fallback, резервные копии |
| `js/voice-data.js` | Наборы реплик; 3D-тексты берутся из существующих игровых данных |
| `js/voice-studio.js` | Экран взрослого, микрофон, индикатор уровня, сохранение/сравнение дублей |
| `js/voice-processing.js` | Локальный анализ, обрезка краёв, выравнивание и WAV |
| `css/voice.css` | Отдельные стили студии |
| `tests/voice.cjs` | Проверки подстановки, реальной записи с тестовым микрофоном, переноса и офлайн |

Аудио: прежняя IndexedDB `speechplay-voice`, версия 1, store `clips`, значения Blob. Ключ прогресса/настроек `speechplay.v3` сохранён; добавлены необязательные `voiceGain` и прежний `voiceEnhance`. Дополнительные текстовые списки фраз лежат в `speechplay.voice.library.v1`; аудио в localStorage не помещаются. Очистка данных браузера удаляет библиотеку. Ни синхронизации, ни облачной копии нет.

После правки исходников — `npm run build`. Готовые ресурсы имеют хэшированные пути `js/release/v16/` и `css/stylesheet-v16-*`; стартовая страница — `release-v16.html`. Новый кэш — `matvey-v16-local-voice-1`. Прогресс, заметки и аудио для обновления не очищаются.

## Проверки

- Прежние наборы smoke/regression, кафе с тремя рецептами, fallback WebGL и все раунды посылок/сада прошли на выпуске v16.
- `npm run test:voice`: реальные MediaRecorder/IndexedDB/WebAudio в Chromium с синтетическим входным WAV; сохранение, обработка, сравнение, отмена, отказ микрофона и позднее разрешение.
- Подтверждены нормализация «е/ё», повторное использование фраз в длинных заданиях, отсутствие совпадений внутри слов, приоритет длинной записи, завершение отменённых обещаний и fallback при ошибке аудио.
- Проверены экспорт, перенос в чистый профиль без TTS, объединение без перезаписи, отсутствие частичного импорта повреждённой копии и сохранение офлайн. HTTP-загрузок аудио нет; ошибок JavaScript нет.
- Студия проверена на ширинах 320, 390, 768 и 1280 px без горизонтального переполнения.
- Отдельно выполнено обновление с настоящего Service Worker v15: после завершения установки нового комплекта студия открывается офлайн, сохранились прежние байты голосового Blob, 23 тестовые звезды и заметка карточки.

Проверки с синтетическим сигналом подтверждают механику и обработку, но не оценивают качество реального голоса пользователя: образец голоса к этому запросу не приложен.
