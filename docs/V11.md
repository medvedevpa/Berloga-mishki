# Мир Матвея v11

Монолит v10 разделён без внешних зависимостей во время игры. HTML уменьшился с 1 883 587 байт до примерно 33 КБ. Извлечены 29 изображений WebP/SVG; канонический PNG и иконки сохранены. Это уменьшение именно HTML, не всей загрузки: изображения теперь скачиваются отдельными файлами.

## Где править

| Файл | Назначение |
| --- | --- |
| `index.html` | Экраны, кнопки, доступные подписи |
| `css/base.css` | Общие компоненты, базовые занятия, ранние стили |
| `css/montessori.css` | Сортировка, фигуры, кормление |
| `css/storybook.css` | Общая сказочная тема, карточки и мастерская |
| `css/discovery.css` | Лесная школа |
| `css/parent-review.css` | Проверка карточек |
| `css/forest.css` | Оформление v11, карусель, семейные награды, адаптивность |
| `js/artwork.js` | Имена изображений и соответствия эмодзи |
| `js/lesson-data.js` | Слова, жесты и наборы базовых занятий |
| `js/adventure-data.js` | Задания и позиции лесных приключений |
| `js/montessori-data.js` | Цвета, фигуры, друзья и инструкции |
| `js/live-data.js` | Живые карточки и фразы |
| `js/discovery-data.js` | Каталог и задания 12 игр школы |
| `js/app.js` | Существующий игровой движок, аудио, хранение и обработчики |
| `js/family-rewards.js` | Семейные задания, жетоны, приз и обмен |
| `js/visuals.js` | Привязка изображений к статическим экранам |
| `js/pwa.js`, `sw.js` | Регистрация и полная офлайн-загрузка |
| `assets/` | Персонаж, животные, растения, фоны |

Скрипты загружаются последовательно в конце HTML. Данные объединяются в `MATVEY_GAME_DATA`, движок получает их при запуске. Семейные награды используют узкий адаптер `MatveyFamilyStore` и тот же объект сохранения. В этой версии движок намеренно сохранён единым: дальнейшее разделение аудио и обработчиков требует отдельной миграции общего состояния. Старый порядок CSS сохранён; оформление v11 применяется последним. Встроенные SVG геометрических фигур остаются процедурными компонентами JavaScript.

## Что изменилось для семьи

- Лесной главный экран с каноническим мишкой, крупными плитками и деревянной вывеской.
- В живых карточках одно крупное животное, предыдущая/следующая карточка и ряд миниатюр. Сохраняются индивидуальные анимации, озвучка, скрытие и исправление фраз родителем.
- У карточек есть короткая идея для совместной игры с настоящей игрушкой.
- Базовые занятия после успеха ждут нажатия «Дальше». Кнопка включается не раньше трёх секунд от начала задания. Без ответа перехода нет.
- Семейные жетоны отделены от игровых звёзд. Взрослый подтверждает попытку слова, звука или жеста в реальной игре, один раз за каждое из четырёх заданий в день. За 1, 5 и 15 подтверждений открываются значки.
- Название приза и стоимость 1–100 задаёт взрослый. Например, прогулка, книга вместе или мороженое. Обмен требует достаточного баланса и дополнительного подтверждения. Призы не выдаются автоматически.
- Управление наградами защищено арифметическим вопросом; это детский барьер, не средство безопасности от старших пользователей.
- Запись голоса освобождает микрофон при ошибке настройки рекордера.
- Учтён `prefers-reduced-motion`, разрешён браузерный масштаб.

## Данные и PWA

Ключ `speechplay.v3` и база `speechplay-voice` не изменены. Новый раздел `familyRewards` добавляется только при сохранении семейной операции. Существующие записи и заметки не удаляются. Экспорт проверки карточек по-прежнему содержит только замечания и исправления, а не все данные или аудио. Жетоны хранятся локально на одном устройстве; синхронизации между телефонами нет.

Service Worker кэширует все ресурсы приложения до активации новой версии, обслуживает их из целостного кэша, удаляет только старые кэши с префиксом `matvey-`. При изменениях повысить `CACHE` в `sw.js`; при добавлении файлов запустить `python3 tools/update-cache.py`. После обновления закрыть и снова открыть PWA. Для микрофона нужен HTTPS или localhost. Офлайн TTS зависит также от установленных системных голосов.

## Проверка

Проверено автоматическим Chromium в Linux:

- Главная 320, 390, 768, 1280 px без горизонтального переполнения.
- Открытие основных разделов и всех 12 игр школы на этих ширинах, открытие игры в альбомном размере 844×390.
- Сортировка всех шести шариков; фильтрация скрытой карточки и сохранение исправленной фразы после перезагрузки.
- Карусель, начисление и сохранение жетона, блокировка повторной отметки, изменение приза, обмен, запрет обмена при недостаточном балансе.
- Кнопка «Дальше» сначала недоступна, после 3 секунд доступна, задание не меняется само.
- Долгое нажатие 1,2 секунды даёт одну награду.
- Уменьшение анимаций, офлайн-перезагрузка с изображениями, запуск в подпапке `/Berloga-mishki/`.
- Нет JavaScript-ошибок и HTTP-ошибок ресурсов в этих сценариях.

Для повторения: установить dev-зависимости `npm install`, браузер `npx playwright install chromium`, запустить HTTP-сервер на 8765 и `npm test`. Можно задать `CHROMIUM_PATH` для установленного Chromium и `MATVEY_TEST_URL` для другого адреса. Скриншоты тестов сохраняются во временный каталог.

Реальный iPhone, запись с физического микрофона, качество TTS и все варианты перетаскивания на сенсорном устройстве не проверялись. Визуальная версия использует существующие иллюстрации и приближает композицию к референсам, но не воспроизводит их пиксель в пиксель.
